# HuffmanCompressor 🗜️

A Java-based file compressor & decompressor using Huffman Coding. Built using Greedy Algorithm, Priority Queue, and Binary Trees. No external libraries used.

## Features
- Compress any `.txt` file
- Decompress `.huff` compressed files
- CLI interface
- Written in clean OOP Java

## Tech
- Java
- DSA: Greedy, Min Heap, Tree

## Folder Structure
- `src/huffman`: Java source files
